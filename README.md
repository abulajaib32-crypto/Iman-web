# Iman-web
IMAN Frontend Track Website
A responsive website for the Frontend Track of IMAN Elevate Bootcamp. It explains the track, what students learn, why IMAN Bootcamp, student projects, testimonials, FAQ, and a registration form.
Technologies
HTML5
CSS3 (Flexbox, Grid, media queries)
JavaScript (no frameworks)
Google Fonts (DM Sans)
Main features
Works on phones, tablets, and computers
Mobile menu that opens and closes
FAQ accordion
Project filter (All, HTML, CSS, JavaScript)
Testimonial slider
Contact form with validation (name, email, phone, message). No backend is used.
Project structure
Contact form with validation (name, email, phone, message). No backend is used.
